# YORA

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».
Рішення Visual Studio називається `SocialProfiles`.

**YORA** — веб-застосунок соціальної мережі, де користувач сам оформлює власну
сторінку: обирає тему й кольори, додає аватарку, банер і фонове зображення,
змінює порядок блоків та спілкується на стіні коментарів.

## Можливості

- Реєстрація та вхід (ASP.NET Core Identity)
- Профіль: назва, «Про себе», аватарка, банер, фон (PNG, JPG, GIF, WebP)
- Теми «Нічна» і «Світла», власні кольори з перевіркою контрасту (мінімум 4.5)
- Редактор із живим попереднім переглядом
- Зміна порядку блоків профілю
- Стіна коментарів: коментарі, відповіді, видалення
- Підписки та лічильники підписників
- Перегляд чужих профілів (`/u/ім'я`) і пошук за іменем

## Технології

C#, .NET 8, ASP.NET Core Blazor (Interactive Server), Entity Framework Core,
SQLite, ASP.NET Core Identity, xUnit.

## Структура

- `SocialProfiles.Core` — предметна логіка (`Domain`), сервіси та інтерфейси сховищ (`Application`)
- `SocialProfiles.Web` — Blazor-інтерфейс, EF Core, збереження файлів
- `SocialProfiles.Tests` — модульні та інтеграційні тести
- `docs` — діаграми, скриншоти, демонстраційні дані

## Запуск

Вимоги: .NET 8 SDK (https://dotnet.microsoft.com/download/dotnet/8.0) та браузер.

1. Один раз довірте сертифікату розробки:

```
dotnet dev-certs https --trust
```

2. З кореня репозиторію:

```
cd SocialProfiles.Web
dotnet run --launch-profile https
```

3. Відкрийте https://localhost:7126

Також можна відкрити `SocialProfiles.sln` у Visual Studio 2022 і натиснути F5.

Базу даних (SQLite, файл `app.db`) і всі таблиці програма створює сама під час
першого запуску. Підтвердження пошти вимкнено, листи не надсилаються.
Паролів і секретних ключів у репозиторії немає.

## Демонстраційні дані

Щоб побачити готові профілі з картинками, **до першого запуску** розпакуйте
`docs/demo-data/demo-data.zip` у папку `SocialProfiles.Web`, щоб поруч із
файлом `SocialProfiles.Web.csproj` з'явилися `app.db` і папка `App_Data`.
