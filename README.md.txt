# SocialProfiles

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».

Веб-застосунок соціальної мережі, у якому користувач може налаштовувати
зовнішній вигляд своєї сторінки: кольори, шрифт, готові теми, порядок блоків.

## Технології

- C#, .NET
- ASP.NET Core Blazor Web App (Interactive Server)
- Entity Framework Core, SQLite
- ASP.NET Core Identity
- xUnit

## Структура

- `SocialProfiles.Core` — предметна логіка (Domain) і сервіси (Application)
- `SocialProfiles.Web` — Blazor-інтерфейс, робота з базою даних
- `SocialProfiles.Tests` — модульні тести
- `docs` — діаграми та макети
